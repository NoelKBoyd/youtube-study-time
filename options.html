YouTube Study Time - Settings

YouTube API key

The study feed uses the YouTube Data API. You need your own free API key, so the daily limit is yours alone.

  1. Open the Google Cloud Console and create a project (free, no billing needed).
  2. Enable YouTube Data API v3 for that project.
  3. Go to Credentials, click Create credentials → API key, and copy it.
  4. Optional but recommended: edit the key and restrict it to YouTube Data API v3.
  5. Paste it below and click Save.

Daily limit

By default a key gets 100 searches per day. Each new page of results (up to 50 videos) is one search. Results are saved for 24 hours, so repeating a topic is free. The limit resets at midnight Pacific time. Testing the key uses one search.
